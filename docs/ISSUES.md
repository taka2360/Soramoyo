## 見た目・描画

## 雲モデル（物理）
- [ ] **雲頂がやや高い（BOMEX: 1.86 km、参照 1.5〜1.8 km）／陸上の晴天積雲は実測より浅い（〜1.4 km、実測は午後 2.5〜3 km）**。
- [ ] **地表バルク式に安定度補正がない**（中立係数＋実効風速の下限 1 m/s）。夜の安定層・昼の不安定時の熱交換が粗い。
- [ ] 地表日射の雲による減衰は真上の柱の光学的厚さだけで計算（太陽方向に傾けていない）、2流近似の目安式。
- [ ] 気孔の日射応答は簡略式（β×(0.1+0.9·min(1,SW/400))）。
- [ ] 鉛直不等間隔格子でも移流の補間式は等間隔用のまま。
- [ ] 拡散は簡略形（応力テンソルではなく ν∇²）。
- [ ] **氷相は SAM 型の簡易な1モーメント**（雲の凝結物・降水を温度で水/氷に分ける）。過冷却水の持続や氷晶核の条件は表現しない。雨と雪は温度で分ける1つの量、あられ・ひょうは別の量（着氷の度合いを持たないので、雪→あられの変換は雲水量に比例する時定数 300 s の近似）。
- [ ] **雲氷が落下しない**（かなとこ雲・巻雲の尾流雲が出ない、かなとこが残りすぎる可能性）。
- [ ] 積乱雲の最大上昇流が強め（Weisman–Klemp 128²/500m で ~50 m/s）。
- [ ] **積乱雲のかなとこが計算領域（64 km 四方）いっぱいに広がる**：あられ追加後も 70 分で高度 7〜10 km の雪が領域平均 ~0.3 g/kg、雪の柱量 50 g/m² 超の範囲が 26%。
  上空 −40℃ では空気が雪をほとんど昇華させられない（飽和までの余地が ~0.1 g/kg）ので、本物のかなとこも何時間も残り 100 km 以上に広がる。周期領域では反対側から戻ってくるため、真下では曇って見える。領域の拡大（または遠方を別扱い）が根本対策。
- [ ] **層積雲（DYCOMS-II）は雲水量がやや多め**（LWP 72 g/m²、参照 20〜60）・雲底がやや低い（0.51 km、参照 0.6 km）。鉛直 10 m 格子（本家は 5 m）。
- [ ] 日射による雲頂の加熱（昼に層積雲が薄くなる効果）がない。雲の長波放射は DYCOMS-II の簡易式で、氷雲にも同じ係数。
- [ ] 全水量の監視：外部強制（沈降・乾燥化）がある場合は保存量でない。蒸発の積算は統計の読み出し間隔で近似。
- [ ] 大規模強制の沈降は柱内で下から順に更新する近似（上昇流のとき更新済みの値を参照）。

## 解決済み（段階6の後の確認で）
- 雲海の縞模様・積乱雲の水平な層状模様 → レイマーチの刻みと雲の面の干渉（エイリアシング）。雲の無い所は粗く、雲に当たったら1歩戻って細かく進む方式に変更。
- 自動露出のリセット直後に雲が半精度の上限を超えて Inf → NaN になり、画面全体が黒くなる → 雲の出力を頭打ち、合成で NaN/Inf を除外、リセット値を昼間程度に。
- 雲の時間蓄積の履歴に NaN が残り続ける → 履歴側にも防御。
- 数値拡散でにじみ出たごく薄い雲水が、遠くを見ると霧のように効く → 0.0005〜0.005 g/m³ 以下は晴れとみなす。
- 微物理の書き直し後の再検証：BOMEX（雲底0.52km 雲頂1.84km 層雲量6.6% LWP6.6）、湿潤気泡（w 16.07 m/s）、Straka（θ′ −9.76 K）はいずれも以前と同じ。

- 積乱雲の雪が溜まりすぎる → 原因は「雪の作りすぎ」ではなく「落ちない」こと。上昇流で持ち上げられた雨が温度だけで雪扱いになり、約1 m/s でしか落ちなかった。
  あられ・ひょう（qg、常に氷、5〜10 m/s で落下し 0℃ 以上で融解）を予報変数に追加。雪・凍った降水が過冷却の雲水を集めるとあられになる。
  WK 128²/500m：50 分後の雪の柱量（領域平均）1400 → 670 g/m²、地上の降水の最大 0.84 → 4.0 g/kg。湿潤気泡（w 16.07 m/s）・BOMEX（雲底0.48km 雲頂1.84km LWP6.2）は変化なし。

## 夜空（段階2）
- [ ] **月面に模様（海・クレーター）がない**。一様なアルベドの Lommel–Seeliger 則のみ。NASA の月面テクスチャ（LRO, パブリックドメイン）を使うにはダウンロードが必要（この環境から NASA のサイトに接続できなかった）。
- [ ] **天の川は輪郭カタログ（5段階）をぼかしたもの**。段階→表面輝度の対応は目安。暗黒帯の細部や色の変化は出ない。実測の全天画像（星を除いたもの）があれば置き換えたい。
- [ ] 恒星は 8 等級まで（約4.1万個）。それより暗い星は天の川の輪郭に含まれる分だけ。固有運動・年周光行差は未補正（数十秒角）。
- [ ] 惑星（金星・木星など）がない。
- [ ] 月食（地球の影）・黄道光・流星はない。
- [ ] 月の明るさは Allen の等級式。月明かりの色は太陽光と同じと近似。地球照の輝度は「新月で約 0.5 cd/m²」の目安。
- [ ] 光害は天頂の明るさと地平線方向への増え方の経験式（Garstang モデルのような都市の位置・距離の計算ではない）。雲底を照らす光害も簡易な係数。
- [ ] 夜の雲の照明（月光・光害）は画面で未確認。
- [ ] 暗所視は桿体の感度を sRGB の重みで近似した簡易な混合。視力の低下（ぼやけ）は未実装。
- [ ] 夜の自動露出の下限（順応輝度 3×10⁻⁴ cd/m²）とキー値の下限は見た目で決めた値。
- [ ] 星の瞬きは周波数を決め打ちした簡易モデル。
